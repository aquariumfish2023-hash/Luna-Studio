# Luna Studio — PWA de edición de fotos

Primera versión de una aplicación gratuita, instalable en Android y preparada para GitHub Pages.

## Funciones incluidas
- Abrir una foto desde el celular.
- Agregar texto con color, tamaño, estilo y contorno.
- Añadir emojis/stickers y moverlos arrastrando sobre la imagen.
- Cargar una imagen propia como sticker.
- Filtros: original, cálido, blanco y negro, vibrante, suave y soñado.
- Estilos/marcos: Polaroid, romántico, cumpleaños, naturaleza y brillante.
- Deshacer cambios, reiniciar y exportar como PNG.
- PWA con caché para abrir la app después de la primera visita.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo, por ejemplo `luna-studio`.
2. Sube **todos los archivos de esta carpeta** a la raíz del repositorio.
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`, guarda y espera a que se publique.
6. Abre la URL que GitHub Pages te muestre. Desde Chrome en Android, menú ⋮ → **Añadir a pantalla principal** o **Instalar aplicación**.

## Privacidad y límites de esta versión
Las imágenes se editan en el navegador y no se envían a un servidor. Esta versión está enfocada en fotos estáticas; no incluye música ni exportación de video. Las fotos se descargan como PNG. La app utiliza una fuente web opcional; si no hay internet, usará fuentes locales del sistema.
